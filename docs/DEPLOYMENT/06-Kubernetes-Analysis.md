# Kubernetes for Portfolio: Worth It?

## TL;DR: NO ❌

**For your use case (portfolio, pause when not using, limited budget):**

| Factor | EC2 | Kubernetes |
|--------|-----|-----------|
| **Setup Time** | 30 mins | 4-8 hours |
| **Monthly Cost** | ₹80-100 | ₹200-500 |
| **Pause/Resume** | 2 clicks | Complex |
| **Resume Link** | Simple | Complex |
| **Learning Value** | Medium | High |
| **Portfolio Value** | Medium | High |
| **Complexity** | Low | High |

**Verdict**: Use EC2 for portfolio. Use Kubernetes to LEARN Kubernetes separately.

---

## Recommendation

**Phase 1**: Deploy on EC2 (this week)
- Follow [[DEPLOYMENT/03-On-Demand-Portfolio]]
- ₹80-100/month when active

**Phase 2**: Learn Kubernetes (optional, later)
- Separate learning project
- Run Jenkins/K8s locally
- No ongoing costs
